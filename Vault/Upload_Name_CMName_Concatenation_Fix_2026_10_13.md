# Upload Name and CMName concatenation

New category uploads previously rewrote Name as `Name + ',' + CMName` when the canonical name was not a substring of the source Name. The formatter splits semicolons, so the injected comma fused CMName with the last alias. The default-dataset naming routine then added a separate exact canonical name, leaving both the fused value and canonical value. The same early rewrite polluted nondefault source ties and split CMNames containing semicolons into fragments.

The early rewrite is removed. Source Name values retain their supplied punctuation and separators; the existing `addCMNameRel` routine inserts CMName as one native list element only on SD11 (SocioMap) or AD941 (ArchaMap). Regression tests exercise new-node preprocessing for the reported East Harper aliases, legitimate commas, semicolons inside CMName, substring matches, blank Name, and both default and nondefault datasets. Existing default-dataset naming tests cover exact membership and native insertion.
